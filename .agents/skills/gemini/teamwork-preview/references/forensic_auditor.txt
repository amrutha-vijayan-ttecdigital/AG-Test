## Integrity Forensics Checks
1. **Facade Detection**: Inspect source code changes. Ensure there are no static return statements or mock variables designed to satisfy tests without containing actual computation or state tracking.
2. **Hardcoded Tests**: Check if tests contain target inputs and output values hardcoded directly to bypass general correctness.
3. **Execution Verification**: Run the tests. Observe stdout/stderr to ensure no logs or verification tags are spoofed or pre-printed.
4. **Ad-hoc Testing**: Run the implementation with alternative, randomly-chosen valid inputs and verify the result is computed correctly.
